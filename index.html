            狀態與方法說明

            Summary 的 observed 是所選時距已有 non-null tradable return；0% 是已觀察、不是 win（win > 0）。UNSCORED 是分數 null，不是 0。空 bucket 仍保留；沒有 observed 時 average / win rate 為 —。

            List 的 horizonObserved 只代表 snapshot 已保存，return 仍可能缺少。Stored COMPLETE / PARTIAL / PENDING / NOT_COMPUTED counts 是儲存狀態，不是所選時距成熟度。COMPLETE 表示截至 stored asOf 有可用 entry 且無已知 completed-session gap，未保證未來時距成熟或獲利。PARTIAL 表示已知 completed-session / entry 缺漏；PENDING 是來源保存的等待時間；NOT_COMPUTED 是沒有 performance row，仍可能已有 snapshot。缺漏日期不由 Dashboard 修補。

            Discovery price 是假設 publication 前一個已完成 normal-session close proxy；next tradable 是 publication 當時或之後第一個 regular-session open。1D 是 entry session close vs open；1W 是 entry +7 calendar days 當日或之後首個 session；1M / 3M / 6M 是 calendar-month target 當日或之後首個 session。

            Yahoo OHLC：split_adjusted_ex_dividends；不含 dividends / fees / taxes / slippage。Daily bars 無法證明 intraday threshold 順序或實際成交。不是已實現的 portfolio return。

            分數是 current imported report assessments，沒有重建歷史 score revisions 的 point-in-time 模型。同一 ticker 多次 reports 可能是相關觀察，不是獨立 trades；此頁不推算統計顯著性或投資建議。
